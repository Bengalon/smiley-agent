# Clutch: פרסומות וידאו (גרסה 2, "תהמר על עצמך")

חמש פרסומות אנכיות (1080x1920, 30fps) לאתר Clutch. כולן בנויות על אותה זווית:
**עד היום הימרת על המזל. מהיום, תהמר על עצמך.**

| קומפוזיציה | אורך | קול | הקונספט |
|---|---|---|---|
| `Clutch-Short-14s` | 14 שנ' | גבר (Brooks) | "רולטה? מזל. קוביות? מזל. מכונות? מזל. פה? רק אתה." |
| `Clutch-TwoPlayers-20s` | 20 שנ' | גבר (Brooks) | מסך מפוצל: אחד מהמר על רולטה ומקווה, השני מהמר על עצמו ושולט |
| `Clutch-Challenge-20s` | 20 שנ' | אישה (Maya) | "למזל לא אכפת כמה אתה טוב. לנו כן." ואתגר 3-2-1 לצופה |
| `Clutch-Manifesto-33s` | 33 שנ' | גבר (Orion) | מניפסט: קוביות, גלגל, ידית, ומי ניצח? המזל. אבל מה אם ההימור הוא עליך? |
| `Clutch-Story-44s` | 44 שנ' | גבר (Orion) | סיפור קולנועי: שנים של הפסדים למזל, ולילה אחד של דו-קרב, פיגור, סיבוב קלאץ' ×3 וניצחון |

הסרטונים הסופיים נמצאים ב-`deliverables/`.

## איך זה בנוי

- **צילומים קולנועיים** (`public/clips`): 14 שוטים שנוצרו ב-Higgsfield. קודם תמונות פתיחה ב-Nano Banana Pro, עם דמות ראשית עקבית מתמונת רפרנס, ואז אנימציה ב-Kling 3.0 Pro. שני עולמות: מזל (קזינו, רולטה, קוביות, סלוטים, הפסד, בגרייד טיל-ענבר) ועצמך (מיקוד, עין, טאפ, ניצחון, בניאון ליים-סגול).
- **מערכת מוושן** (`src/v2`):
  - `Shot.tsx` שוט עם תנועת מצלמה, גרייד, פאנץ'-אין עם zoom blur, whip-pan עם טשטוש תנועה, zoom-through וגליץ' RGB.
  - `Fx.tsx` ניפוץ זכוכית תלת-ממדי, light leaks, הבזקי עדשה אנמורפיים, letterbox, גריין, אבק אור, sweep ושייק מצלמה.
  - `Type.tsx` טיפוגרפיה קינטית בעברית: slam עם פיצול RGB, mask rise, plate, קו מחיקה ומספרים רצים.
  - `Three.tsx` לוגו Clutch מוחצן בתלת-ממד, וקלפי משחק תלת-ממדיים שמתהפכים בחלל.
  - `Scenes.tsx` טלפון תלת-ממדי שמריץ סיבוב אמיתי מהמשחק, מסך VS מפוצל, מסך ניצחון עם גשם צ'יפים, כרטיס סיום ו-countdown.
- **קריינות** (`public/vo2`): טייק רציף אחד לכל פרסומת (ElevenLabs v4 דרך Higgsfield). השקטים מקוצרים אוטומטית ל-0.12 שנ', וההגייה נבדקה בתמלול Whisper. כל קאט וכל מילה על המסך מסונכרנים למילים בקריינות.
- **סאונד** (`audio-src/trailer.py`): מוזיקה ואפקטים מסונתזים בקוד, מקוריים וללא זכויות יוצרים. חלק אפל ופועם על המזל, build, ודרופ טראפ (808, היי-האטס, סנר) בדיוק ברגע המפנה. בנוסף braam, hit, ניפוץ זכוכית, sub drop ו-whooshes.

## הרצה

```bash
npm i
npm run dev                                  # Remotion Studio
scripts/render-all.sh                        # רינדור כל 5 + מאסטרינג אודיו (-14 LUFS) ל-out/final
scripts/render-all.sh Clutch-Short-14s       # רק אחת
node scripts/stills.mjs Clutch-Story-44s /tmp/s 100,500,900   # פריימים לבדיקה
python3 audio-src/trailer.py public/sfx2 && (cd audio-src && python3 make_music2.py ../public/music2)   # חידוש אודיו
```

תלת-ממד ואפקטי WebGL במכונה בלי GPU דורשים `--gl=swangle` (מוגדר ב-`remotion.config.ts`).
