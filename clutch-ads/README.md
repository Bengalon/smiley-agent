# Clutch: 5 פרסומות וידאו (Remotion)

חמש פרסומות אנכיות (1080x1920, 30fps, מתאים לרילס/טיקטוק/סטוריז) לאתר Clutch, דו-קרבות מיומנות 1 על 1.
כל הוויז'ואל בנוי בקוד ב-Remotion, לפי ה-PRD ועיצוב האתר (צבעים, פונטים, קלפים, HUD, סיבובי קלאץ', אפקטים).
הקריינות בעברית נוצרה ב-Higgsfield (ElevenLabs v4). המוזיקה והסאונד מסונתזים בקוד, מקוריים וללא זכויות יוצרים.

|---|---|---|---|---|
| 1 | `Ad1-Hype-15s` | 15 שנ' | ללא (מוזיקה + SFX) | "תחשוב. תגיב. תיקח את הקופה." טיזר דופמין מהיר: לוגו, 2 סיבובים, סיבוב אחרון ×3, ניצחון, CTA |
| 2 | `Ad2-NotLuck-36s` | 36 שנ' | גבר (Brooks) | "לא מזל. סקיל." עולם אפור של רולטה/סלוטים/קוביות, מעבר דרמטי ל-Clutch: אותם סיבובים לשני השחקנים, מכפילים, ניצחון |

הסרטונים הסופיים: `deliverables/` (אחרי מאסטרינג אודיו ל-‎-14 LUFS).

## הרצה

```bash
npm i
npm run dev                      # Remotion Studio, תצוגה מקדימה ועריכה
scripts/render-all.sh            # רינדור כל 5 הפרסומות + מאסטרינג אודיו ל-out/final
scripts/render-all.sh Ad1-Hype-15s   # רק פרסומת אחת
node scripts/stills.mjs Ad4-ClutchMoment-56s /tmp/stills 100,500,900   # פריימים בודדים לבדיקה
```

רינדור תלת-ממד (three.js) במכונה בלי GPU דורש `--gl=swangle` (מוגדר ב-`remotion.config.ts`).

## מבנה

- `src/brand.ts` טוקנים מה-PRD (צבעים, גרדיאנטים) ופונטים מקומיים (Unbounded, Manrope, Heebo לעברית) ב-`public/fonts`.
- `src/components/` אבני הבניין:
  - `Round.tsx` סיבוב משחק מלא: חלוקת קלפים, היפוך תלת-ממדי, טיימר, טאפ, חשיפה, באנר נקודות, קונפטי ומטבעות.
  - `GameScene.tsx` מסך משחק עם HUD (ניקוד, מסלול סיבובים, מכפיל).
  - `Screens.tsx` מסך VS עם ספירה לאחור, Takeover של סיבוב קלאץ', מסך ניצחון, כרטיס סיום, כתוביות.
  - `Chips3D.tsx`, `Scenes3D.tsx` צ'יפים, קוביות, מטבעות ורולטה בתלת-ממד (three.js), מגדל הצ'יפים מהאתר, גשם צ'יפים, פיצוץ צ'יפים.
  - `Extras.tsx` מכונת מזל, גליץ', מסך מפוצל "אותו סיבוב", כרטיס דו-קרב, סולם מכפילים, קיר 176 סוגי סיבובים, חלוקת הקופה.
  - `Voice.tsx` קריינות, דאקינג אוטומטי של המוזיקה מתחת לקול, כתוביות מסונכרנות.
- `src/ads/` חמש הפרסומות. כל הזמנים מוגדרים בשניות ומסונכרנים לקריינות ולביטים של המוזיקה.
- `audio-src/` סינתיסייזר פייתון: `make_sfx.py` (אפקטי הסאונד של האתר, הועתקו מ-Web Audio, ועוד אפקטים קולנועיים), `make_music.py` (מוזיקת רקע לכל פרסומת, עם דרופים בזמנים של הוויז'ואל).
- `public/vo/` קריינות עברית (מנורמלת ל-‎-16 LUFS). `public/music/`, `public/sfx/` הסאונד.

## הקריינות (עברית)

הטקסטים המלאים נמצאים בקבצי הפרסומות (`VO` + `caps`). כל שורה נוצרה בנפרד ב-Higgsfield, נבדקה בתמלול אוטומטי (Whisper) כדי לוודא הגייה נכונה, ושורות עם הגייה לא ברורה הוקלטו מחדש.

לחידוש אודיו: `python3 audio-src/make_sfx.py public/sfx` ו-`python3 audio-src/make_music.py public/music` (דורש numpy ו-scipy).

## הערות

- הכסף בפרסומות הוא בדולרים, כמו באתר. החישובים תואמים את חוקי ה-PRD: עמלה 5%, ניקוד S, סולמות המכפילים של Sprint/Classic/High Roller.
- בכל כרטיס סיום מופיע "‎18+ בלבד · שחקו באחריות · משחק מיומנות".
